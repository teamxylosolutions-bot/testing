# Custom business education homepage

A responsive Acquisition.com reference recreation in HTML, CSS, and vanilla JavaScript. All artwork is local, lightweight SVG placeholder imagery. No framework, package dependencies, CDN requests, or tracking scripts.

## Run
Open `dist/index.html` directly, or serve the `dist` folder with any static host (for example `python3 -m http.server 8000 --directory dist`). No build is required.

## Customize
- Content and links: `dist/index.html`
- Responsive styling: `dist/styles.css`
- Mobile navigation, dropdowns, resource dialogs: `dist/app.js`
- Images: `dist/assets/` (replace SVGs and preserve intended aspect ratios)

Demo resource buttons open clearly labeled placeholder dialogs. Connect real destinations before launch. The metrics are explicitly illustrative. This is an independent demonstration, not an official Acquisition.com website.

## Hosting
Deploy `dist/` as the public root. `.openai/hosting.json` is used only by the optional private preview host and is not required by other static hosts.
